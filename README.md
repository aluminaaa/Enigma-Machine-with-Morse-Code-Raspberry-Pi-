# Enigma-Machine-with-Morse-Code-Raspberry-Pi-
Code for my Enigma Machine project that I made on Raspberry Pi

# Project
This is a very cheap, online version of the Enigma machine (used during WWII for encrypting messages). This uses the same logic behind it, but (since I couldn't 3D print the actual thing :( , nor did I have 26 buttons to put on my breadboard) it uses one singular button for the input using Morse code 🫩. 

# How it works
- the enigmamachine.ipynb is the enigma machine one
- to decode,
  1. note the start positions and rotors used
  2. change it to match that in enigmadecode.ipynb (there should be a comment)
  3. run enigmadecode.ipynb and input the letters that were outputted from enigmamachine.ipynb

# Things Used
- Python
- Raspberry Pi
- button + jumper wires
- I did use some Gemini for help
